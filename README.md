# PCA, Autoencoders, K-Means Clustering and fcNN

This project explores key methods in dimensionality reduction, clustering, and neural networks, including PCA, autoencoders, K-means, and fully connected neural networks.
The focus is on understanding how these approaches learn patterns in data through implementation and visualization.

## Setup 
```bash
pip install -r requirements.txt
```
## Run
jupyter notebook notebook.ipynb
